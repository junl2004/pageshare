Enter settings the way the app shows them. Produces a backup.json you can restore with the official tool. Record layout taken from src/metadata.h and src/password.h.

    Restoring replaces the entire nickname list on the device. Export your current
    list first and keep that file unchanged. Derivation happens on the Ledger — this file holds no
    password and no seed, only nicknames and their settings.
  






  

A record is [datalen][kind][data block].
  data block = [charset][nickname]                    version 0
             = [charset][password length][nickname]   version 1 and later

  datalen  = bytes in the data block   (0x00 ends the list, 0xFF = erased)
  kind     = 0 or 1, the generation rule
  charset  = bitmask, bit0 UPPERCASE  bit4 UNDERSCORE
                      bit1 LOWERCASE  bit5 SPACE
                      bit2 NUMBERS    bit6 SPECIAL
                      bit3 MINUS      bit7 BRACKETS
Records are packed back to back and zero-padded to 4096 bytes.
Version 0 has no length byte: its length is always 20.

  

    The old app's dashes toggle is SEPARATOR_SETS 0x38 in
    password.h — bits 3, 4 and 5 together. Extra symbols covers
    SPECIAL and BRACKETS. A separator-only alphabet is rejected by the app as weak, and the
    4- and 6-digit PIN lengths require numbers to be the only kind enabled.
